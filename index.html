          六个必须记住的判断

          权钱交易

          受贿的本质不是“收了钱”，而是“钱”与“权”之间形成了对价关系。

          常见误解：不收现金就没事。

          特定关系人

          配偶、子女、情人等特定关系人收钱，本人明知并为其谋利，一样可能构成受贿。

          常见误解：挂在家人名下就安全。

          代持

          房子登记在别人名下，但你能住、能收租、能卖，法律上仍可能是你的。

          常见误解：登记是谁的就是谁的。

          借款型受贿

          有借条不等于借款。关键看有没有归还意思、有没有归还能力、为什么一直不还。

          常见误解：打了借条就是民事借贷。

          期权腐败

          在职办事、离职收钱，时间差不是防火墙。关键看离职前后有没有约定或默契。

          常见误解：退休就“安全着陆”。

          纪法贯通

          同一个行为，可能同时触发纪律责任与法律责任。纪在法前，纪严于法。

          这也是审理意见要分两栏写的原因。

          判定规则

          三个问题，对应受贿认定的三个核心：主体、职务行为、利益对价。规则是简化的，真实案件远比这复杂。

          无请托 + 正常往来                  → 人情
明确请托 + 任一异常                → 受贿
职务影响 + 超常 / 未还 / 无劳务     → 违纪（可能转化）
职务影响 + 时间吻合                → 待核
职务影响 + 正常往来                → 人情
明确请托 + 正常往来                → 违纪（情节较轻）
任一“说不清”                       → 待核

          三个问题分别在问什么

          • 谁收的：本人、近亲属、情人等特定关系人，还是他人代持。主体不同，认定路径不同。
          • 有没有请托：有没有具体的谋利事项。这是“权钱交易”的核心连接点。
          • 是否异常：金额是否超出正常往来、是否长期不还、是否未提供真实劳务、是否与职务行为时间高度吻合。

          为什么用“区间”而不是“标准答案”

          真实案件里，同样的事实，可能因为证据、情节、认罪态度不同，得出不同结论。作品给的是“参考定性”和“可能的区间”，不是判决书。争议条目允许不同判断，这正是专业性的体现。

          作品说明

          纪检监察学 · 专业知识科普 · 教学模拟

          这是什么

          《人情账本》是一件面向公众的互动审理实验。你以纪检监察机关案件审理人员的身份，对十二笔“人情往来”逐条判断：正常人情、违规违纪、涉嫌受贿，还是证据不足待核。

          想讲清什么

          公众对受贿最常见的误解是“只要不收现金就没事”。作品想说明：受贿的本质是“权”与“钱”形成对价；特定关系人收受、代持、借款型受贿、干股、期权腐败，都是隐形变异的形态。判断的关键，不在形式，而在实质。

          为什么是“审理”视角

          审理是纪检监察案件查办的最后一道内部关口：事实清不清、证据够不够、定性准不准、处理当不当。让体验者坐在审理席上，比让他扮演贪官或道德裁判，更接近专业知识本身。
